Folder terpilih

Klik salah satu folder di sebelah kiri.

Folder sumber tiap jenis produk

Tiap jenis produk boleh berada di drive atau komputer yang berbeda — drive lokal, Google Drive yang di-mount, atau folder jaringan. Atur sekali di tiap komputer.

Tombol Pilih… membuka penjelajah folder Windows, bukan dialog browser, karena browser tidak diizinkan membaca path asli sebuah folder. Path juga boleh ditempel langsung ke kotaknya.

Daftar SKU

Di Google Sheet: File → Download → Microsoft Excel (.xlsx), lalu pilih berkasnya di sini. Format .xlsx lebih baik daripada CSV karena membawa semua tab sekaligus.

Tidak perlu mengubah susunan sheet. Tools mencari sendiri baris judul yang memuat kolom Nama Produk, Varian, dan SKU; baris riset di atas tabel diabaikan. Jenis produk diambil dari awalan SKU (JB-, PA-, PB-).

Berkas lama dicadangkan ke data/sku.csv.bak.

Template Shopee

Shopee menolak berkas yang dibuat dari template lama dengan pesan “harus menggunakan template terbaru”. Kalau itu terjadi: unduh ulang template dari Seller Centre → Produk → Mass Upload untuk cabang kategori yang bersangkutan, lalu pasang di sini.

Tools menentukan sendiri template itu untuk kategori yang mana dengan membaca daftar kategori di dalamnya, jadi tidak perlu memilih tujuannya. Versi lama dicadangkan ke .bak.

Alamat dasar foto

Akar repo GitHub tempat foto disajikan, contoh https://cdn.jsdelivr.net/gh/pengguna/repo@main. Bagian /foto-upload/... ditambahkan otomatis. Repo harus public — jsDelivr tidak bisa menyajikan repo privat.

4. Export mass upload Shopee

Satu berkas Excel dihasilkan per toko per template kategori. Kalau ada folder yang dipilih di langkah 1, hasilnya ditulis ke output/pilihan/ supaya tidak menimpa hasil lengkap di output/.

Di Seller Centre Shopee: Produk → Mass Upload → Upload berkas, lalu pilih berkas milik toko yang bersangkutan. Ingat tiap berkas hanya untuk satu toko dan satu cabang kategori.

Ekspor daftar URL menulis pemetaan foto → alamat publik ke data/url_foto.csv dan satu berkas per toko di data/url/, berguna untuk mengecek foto yang tidak muncul.
